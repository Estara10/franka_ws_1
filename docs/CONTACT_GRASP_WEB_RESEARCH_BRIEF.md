## 2. 已经跑通与没有跑通的部分

## 3. 驱动与模型参数

### 仿真 XML 声明

以下来自本地当前源码，实际编译模型/运行时覆盖仍需核对；不能只按 XML 注释推断生效值。

```xml
<option timestep="0.002" integrator="implicitfast"
        iterations="50" tolerance="1e-9" solver="Newton"
        jacobian="dense" cone="pyramidal"/>

<position name="mj_left_act_gripper" tendon="mj_left_split"
          kp="1200" forcerange="-150 150"
          ctrlrange="0 0.08" ctrllimited="true"/>
<!-- 右夹爪同类配置 -->
```

- 两指滑动关节各自范围 0–0.04 m；gap=q1+q2，指位不是总 gap。
- 腱长度使用两指各 0.5 的传动，即约 `L=0.5*q1+0.5*q2`。
- 同一夹爪两指之间存在关节 equality 同步关系；它不是手–杆固定约束。
- XML 两指同步 equality 的 `solref="0.005 1"`、`solimp="0.95 0.99 0.001"`。
- 默认继承 joint armature=0.1、damping=1；实际指关节有效惯量/继承值需以编译模型确认。
- 力保持期间添加每指约15.6 N·s/m dof阻尼，总计约16.6；退出后恢复原值。
  该值来自简化临界阻尼估算，并非通过接触动力学辨识得到，合理性待审视。

### 接触几何与参数

杆 box 半尺寸为0.02/0.20/0.02 m。杆 geom：

```xml
friction="3.0 0.5 0.005"
solref="0.005 1"
solimp="0.99 0.999 0.001"
```

原指垫为每指多个 box 接触 geom，声明包含：

```xml
friction="3.0 0.5 0.005" condim="6"
solref="0.01 1" solimp="0.95 0.99 0.001" margin="0.001"
```

`contact_probe` 运行时采用单主指垫 profile：禁用16个辅助pad，仅保留四个主pad。
主pad box半尺寸改为 `(0.010,0.006,0.010) m`，其 `solref` 改为 `(0.02,1)`；
摩擦未改，杆的solref未同步修改。**实际接触对的混合参数不能直接等同于pad参数**，
请检查 MuJoCo 的 priority/solmix、摩擦、margin、condim 组合规则以及 equality 的影响。

### 最新固定预压策略

在接触时锁存腱参考 `L_ref`。正力请求记为每指10 N，按当前0.5传动理解设置
actuator/tendon力限幅 ±20 N。最新策略：

```text
preload = 0.9 * 20 / 1200 = 0.015 m
ctrl_hold = clamp(L_ref - preload, ctrl_min, ctrl_max)
F_actuator ≈ kp * (ctrl_hold - L)
```

显式保持时由物理线程设置 actuator 力限幅，退出恢复原范围。
这里15 mm是位置伺服参考偏移，**不是实际指垫或杆变形15 mm**。
±20 N是actuator力限，不等于垫面法向力。请独立核对传动、单位、符号与公式适用条件。
不得假定 `forcerange` 自动等价于 `forcelimited` 已开启；应检查实际模型标志、
增益/偏置、gear、actuator dynamics 和 `qfrc_actuator`。

早先策略每物理控制更新通过当前腱长度换算受限力对应的ctrl，再加入锁存参考的
恢复项；已尝试用固定参考预压代替，并仍出现振荡。控制调用频率、相对mj_step
阶段和状态更新时间尚未在本材料中给出可靠测量，请勿自行假定全部为500 Hz。

## 5. 当前接触建立门槛与承载门槛

- 接触建立：20个新物理反馈样本，覆盖至少0.18s；每指法向力≥0.25N的样本占比
  至少80%；总gap全窗散布≤0.5mm。最近14/20即70%，没有满足80%。

  并满足相应反馈、受力和释放条件。
- 可以讨论接触建立窗是否过严、是否应以力/滑移趋势而非gap为主，但不能将
  “接触门槛放宽”直接视为解决了085803的未离地问题。
- 不需要工业级零波动、全天候可靠或复杂安全认证。希望低成本、有限次数解决。

## 6. 诊断口径与局限

已记录q1/q2、dq、ctrl、actuator_force、腱长、保持请求、手掌/杆位姿及逐接触CSV。

已修复，但仍欢迎核对当前口径，不能把旧CSV与新CSV直接混用。

因此其竖直力之和不是严格同步、未过滤的完整杆合力；地面支持力也不能混入手指承载力。
