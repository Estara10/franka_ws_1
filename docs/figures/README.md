写结题报告或做PPT，先选 **结题主图** 中的4张。需要补充细节时再看 **辅助图**；**历史归档** 保留原来的实验过程和旧版图，不作为当前主图。

| 图片 | 简洁标题 | 适合说明什么 |

图内只保留坐标、单位、曲线、数据点和必要图例，不放图名、大标题、流程图或结论标语。图名、实验条件和效果解释写在正文，现成文字见[主图图注与说明](主图图注与说明.md)。主图01的A/B与C/D释放等待不同；主图02的jerk为参考指标，O只做了离线比较；主图03、04来自专门的悬空保持/受力试验。完整结果见[结题收口说明](../deliverables/20261022_结题收口_结果.md)。
