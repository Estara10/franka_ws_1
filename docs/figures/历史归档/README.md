# 历史图归档

这里保存旧版统计、早期实验与离线探索图，供查阅原来的实验过程。结题选图先看[图片说明](../README.md)。旧图不删除，也不冒充最新结果。

- **旧版统计**：上一批运行、统计修订前的图，以及旧时间优化方法的对照。
- **早期实验**：早期JTC/MMC悬空保持，包含未补偿时的下沉和残差。
- **离线探索**：单样本、位置/旋转场景探索和依赖假设的去趋势图。
- **技术分析版**：重新绘制中文展示主图前的原版4张图，保留多子图、详细坐标和图注；见[技术分析版目录](技术分析版/)。
