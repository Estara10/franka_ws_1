## 2. 已有结果与补充问题

### 2.1 现有实验有效，不把解释边界当成系统故障

80次实验没有因下述问题失去效力。它们真实记录了四种完整程序配置下的任务完成情况、
释放误差、参考指标和计算开销，可以继续作为报告主实验。
需要区分“当前程序整体表现如何”与“某一算法独立起了什么作用”这两个问题。

**运输前额外计算是什么意思？**四组抬升后都要进行基础规划和阶段衔接，A/C并非完全不等待。
B/D在此基础上还计算并校核时间优化候选，之后才开始运输。优化器平均计算约4.23/4.78 s，
这是墙钟耗时，不能直接当作物体在仿真中额外保持的精确秒数。
代码顺序可见`contact_load_probe.cpp`中的运输基础规划及B/D的`buildTimeProfileCandidate`分支。
执行者应从阶段事件核对实际仿真保持时间，而非仅凭求解计时推算。

**为什么可能影响比较？**如果物体在刚完成抬升时仍有运动，较长保持可能使它回稳；
也可能在等待中继续下沉或发生接触漂移。当前没有证明哪种影响实际发生，更不能据此认定
时间优化的物理效果来自等待。只有当研究要解释“优化组运输中高度变化较小，是否由时间分配
本身造成”时，才需要匹配等待或作额外分析。

**哪些结论仍然成立？**

- 80次正式尝试及79次完整完成是真实结果；原失败和样本定义不变。
- 释放位置、角度误差可描述各自完整配置的表现，但不能单独证明某个算法因素的因果作用。
- B/D参考jerk平均下降约5.64%/4.58%，来自同次基础与候选在相同路径、相同总时长下的比较，
  该参考结论不受运输前等待影响；它仍不代表实测机械臂jerk改善。
- 额外计算和等待是现有优化流程的成本。评价部署效率时应计入，不能通过给基线人为增加等待
  来消除这一代价；匹配等待只服务于另一个用于解释运动响应的补充对照。

其他已知边界也不等于新发现故障：现有C/D同时采用阻抗和前馈，能比较组合，不能从这批数据
单独分离前馈作用；JTC动作墙钟和MMC参考播放的时间定义不同，不能直接跨组排序效率；
已有低频物体及手指记录不能用于声称实测十四关节jerk下降。
这些限制应通过准确表述控制结论范围，不自动变成必须补跑的清单。

### 2.2 如需进一步解释，可补充哪些比较

| 已有结果 | 可支持的表述 | 补充研究要回答的问题 |
|---|---|---|
| 80次完整搬运：A/B/D各20/20，C19/20 | 系统已实现固定场景完整接触搬运，C04保留为未完成 | 不需要再重跑80次证明已实现的功能 |
| B/D候选各20次采用，连续参考jerk RMS均值下降约5.64%/4.58% | 固定路径和总时长的参考平滑度有所改善 | 如需解释物理响应，进一步区分时间映射与计算保持阶段的作用 |
| 释放位置误差均值A/B/C/D约5.63/6.25/10.03/10.53 mm | 时间优化和阻抗组合未显示一致放置精度优势 | 承载过程是否改善，以及与放置误差如何取舍 |
| 前馈开关悬空各3次，下沉中位数约8.37→2.90 mm | 支持该悬空配置下的载荷补偿作用 | 相同阻抗配置下，前馈在完整搬运中带来什么变化 |
| 方向性刚度专项每组3次，让步与残余均增大 | 指定方向可调的顺应性及恢复代价 | 本轮沿用现有专项，不扩展刚度或外力扫描 |

探索性诊断显示，80次运输阶段高度范围的组内中位数约A/B/C/D为7.13/6.96/3.09/1.05 mm，
各组20条运输记录，包含C04已经完成的运输阶段。这提示可能存在高度保持差异，但尚未排除
采样、阶段边界及运输前等待的影响，不能作为新增因果结论或追改原实验主指标。

已确认的是候选计算位于抬升与运输之间；其对实际运动结果的影响尚未验证。
高度范围也不等于目标高度误差或振荡幅值。现有CSV的`left_q1`等为手指位置，
不能用它计算十四关节实测jerk，不能用低频杆位置三次差分替代实测关节jerk。

## 3. 待审查的实施顺序

### 3.1 先做必要的最小修改

以下仅在决定开展补充因果对照时实施，不能作为现有80次实验和结题报告成立的前提。
审查通过并获得执行指令后，复用现有任务、运行器及记录器完成以下改动：

1. **完整搬运前馈开关。**当前完整搬运参考流及桥接启动均开启前馈，
   `CONTACT_PROBE_PAYLOAD_FEEDFORWARD`只影响悬空分支。新增完整搬运开关并默认保留原行为，
   同时覆盖激活、运动参考、段间保持和桥接配置。关闭时实际发送的载荷前馈须为零；
   阻抗增益、模型补偿等保持相同，不能把物体前馈关闭等同于关闭机器人本体重力补偿。
2. **候选计算与选用分开。**允许同样生成候选后选择基础或优化参考，固定空间路径和总时长。
   计算前移至无承载阶段只有在不改变实际起点与路径构造的条件下才可采用，不能直接重用失配的旧起点。
3. **在补充对照中匹配运输前保持。**这用于解释算法的运动作用，不是修复已经确认的运动故障。
   拟让两条件均计算候选，并采用共同的运输前保持规则。
   “都计算”不自动等于保持时间相同；需记录从抬升结束到运输下发的仿真时长。
   优先采用事先固定的共同运输启动时刻，等待长度由已有耗时与仿真时间记录估计、经审查后冻结。
   不能在运行中只为优化组追加等待。若该方式改动过大，审查器可提出更简单的等效方案。
4. **统一物体数据时间。**以物体真值对应的仿真时间记录阶段开始和结束，统一分析采样规则。
   优先复用现有字段；确有缺口时只补真值时间和阶段事件，不建立通用采集框架。

只做相关定向构建与必要检查，沿用已有碰撞、控制器互斥、限幅和明显失效处理。
当前阶段不改夹持力、摩擦、质量、刚度、优化目标或保护值。

### 3.2 共享基础组的探索性对照

首选4条件×3区组，共12次正式尝试；每区组各条件一次，顺序预先固定并适度平衡。
四种条件共用已验证场景、抓取流程、基础赋时、匹配等待与采样方式：

| 条件 | 运输参考 | 承载控制 | 物体载荷前馈 | 比较用途 |
|---|---|---|---|---|
| P | 基础 | JTC | 不启用阻抗载荷前馈 | 共同基线 |
| T | 时间优化 | JTC | 不启用阻抗载荷前馈 | T/P：时间分配的执行效果 |
| I0 | 基础 | 独立笛卡尔阻抗 | 关闭 | I0/P：控制方式取舍 |
| I1 | 基础 | 同一独立笛卡尔阻抗 | 开启 | I1/I0：前馈作用；I1/P：组合表现 |

这是用于解释已有现象的探索性补充，不替代80次正式主实验，也不用于估计总体可靠率。
若P不能同时满足两类比较的等待和采样条件，则拆分为6次轨迹对照与9次控制对照，
合计15次；审查后只选一种安排，不在看过结果后临时切换分组。

每次参考生成后保存同次基础与候选指标。不同仿真运行因重新抓取、实测起点和IK解而可能不同，
不能宣称跨运行的关节路径逐点相同。执行结果按条件和区组描述，完整保存起始状态与路径差异。
正常基线不需要的候选计算，只是匹配设计的额外开销；需与实际部署的算法计算代价分别报告。

### 3.3 预先固定评价与记录

| 指标 | 计算与解释 |
|---|---|
| 完整任务完成情况 | 从首次预抓取执行请求被接受开始计入，抓取至撤退均完成才记为完成；沿用80次批次定义 |
| 连续参考jerk RMS与峰值 | 候选相对于同次基础参考，同一路径、同一总时长；不称为实测机器人jerk |
| 运输阶段高度净变化 | 阶段末高度减阶段初高度，区分上移与下沉 |
| 运输阶段高度范围 | 同一阶段内最大值减最小值，称高度变化范围，不直接称振荡、跟踪误差或jerk |
| 释放位置和偏航误差 | 统一释放后约2 s仿真等待，缺失值不补零，注明有效测量数 |
| 实际保持、阶段时长与求解耗时 | 仿真时间与墙钟分别记录，不将JTC动作墙钟和MMC参考播放时间直接作速度排序 |

运输窗口以实际运输参考开始至结束为边界，不夹入抬升后计算等待或下降。
采用统一采样时间网格，仅在原始真值覆盖内插值，不外推、不用夹爪时间替代杆真值时间。
若报告目标高度跟踪误差，须具备同一时刻的期望杆高度；否则只报告净变化和范围。
均值、逐次值和必要的范围同时保留，放置误差与承载表现并列呈现。

### 3.4 连续执行与收尾
