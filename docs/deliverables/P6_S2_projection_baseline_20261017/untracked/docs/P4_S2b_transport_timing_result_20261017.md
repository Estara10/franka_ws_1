## 4. 结论

1. **运输时长可以减半而接触不退化**：2.232 s → 1.107 s（执行 2.44 → 1.30 s），
   运输滑移反而略低，全流程 `max_slip` 与落点误差同一量级，流程 DONE。
2. S2 的“CHOMP 更快”到此完全解释清楚：差异来自基线的 2× 拉伸，不是规划器能力；
   在相同计时尺度下 CHOMP 没有速度优势，且它不保证双臂闭链。
3. 首次 1× 运行暴露的是**运输后回稳不足**的时序问题，已用有界稳定等待修复；
   该等待对所有配置生效，默认 2× 流程只增加约 100–200 ms。
4. 目前 1× 只有 1 次有效运行（`..._195136`），默认值仍是 2.0；是否把运输拉伸
   改为 1.0 作为新默认，建议在批量重复（至少 3 次）后再定。
