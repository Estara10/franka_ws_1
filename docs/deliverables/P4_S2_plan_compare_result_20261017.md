## 3. 条件执行（Phase 2）

CHOMP 满足 5 mm/2°、无碰撞、无限位/速度/加速度超限，因此同会话执行一次：

- 运输 action 实测约 1.22 s（IPTP 基线 164743/185847 约 2.42–2.44 s）。
- **时长对比的口径警告（已定位）**：基线 `makePlan` 的拉伸公式
  `stretch = max(min_total, min_total/T)` 使 `min_total` 实际成为**拉伸系数下限**；
  运输传入 `min_total=2.0`，计划时长因此正好是 IPTP 原始时长的 **2 倍**
  （2.232 s = 1.116 s × 2）。CHOMP 的 1.083 s 与末拉伸的 IPTP 时长几乎相同。
  所以 2.223 s vs 1.083 s 的差异来自**计时策略**，不是规划器能力；公平对比需把
  运输拉伸改为 1× 后执行一次（任务书
  [`P4_S2b_transport_timing_执行器提示词.md`](P4_S2b_transport_timing_执行器提示词.md)）。
- 运输阶段滑移（`contact_probe.csv` 分阶段最大值）：左 3.66 mm、右 5.62 mm；
  刚性 IPTP 基线为 4.74/5.35 mm（185606）与 5.68/4.82 mm（185847）。
- 运输后重建立、落回、释放完成；`[CONTACT_PROBE_RELEASED]` 显示
  `open=true force_hold=OFF weld=OFF attach=none`。
- 最终杆位姿 `(0.396533, -0.003561, 0.020656)`，偏航 18.82°；
  相对目标 `(0.40, 0.00, 20°)` 误差约 x −3.5 mm / y −3.6 mm / 偏航 −1.18°，
  与刚性基线（约 3.7/2.7 mm、1.35°）同一量级。
- 本轮抬升/保持滑移 13.11 mm，duty `(0.82, 0.97, 0.79, 0.82)`；该阶段不经过
  运输规划器，属于轮次波动（刚性基线为 5.0–7.5 mm），不是 CHOMP 的效果。

## 4. 结论

1. **MoveIt CHOMP 在本场景能生成可行双臂轨迹，且最大双臂残差 4.299 mm / 0.977°，
   满足 5 mm/2°。** 但它不感知“双手–杆”闭链：残差来自优化目标（平滑、避障）的
   副作用，不是被约束住的量，比物体空间 IK+IPTP 的 0.085 mm 大约 50 倍。
   因此不能把“CHOMP 满足闭链”当作一般性结论，只能作为本固定场景下的一次对照。
2. CHOMP 的隐含杆路径基本是直线（横向偏差 1.0 mm），计划 1.083 s；基线末拉伸的
   IPTP 时长约 1.116 s，运输段的 2.232 s 是 `min_total=2.0` 的 2× 拉伸所致。
   **两者在计时上基本一致，CHOMP 没有速度优势**；jerk 约为基线的 2–3 倍，
   运输滑移没有明显改善。
3. **默认执行路径保持物体空间 IK + IPTP**（闭链由构造保证）。CHOMP 作为 S2
   的对照证据记录，不替换默认运输规划。
4. 若后续要使用 CHOMP，需要额外做“优化后投影/修正 + 重新验证”（阶段计划 P4
   的要求），本轮未做。
