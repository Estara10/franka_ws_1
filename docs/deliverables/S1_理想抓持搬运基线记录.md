## 实际链路

默认仍为 `grasp_model=none`，`grasp_contact_close=false`。`--grasp-model ideal_weld` 才会打开 A1 真值→P2a/P2b→预抓取→打开→严格下降→理想抓持链，并与真实接触闭合和空载自检互斥。节点运行日志实际读到 `grasp_model=ideal_weld`。该模式不要求双指接触，也不声称摩擦夹持或抗滑。

双手在抓取位姿后，任务读取物理杆真值和当前双手 FK，冻结 `object→hand` 变换；物理线程确认左右 dual weld 已启用；确认 PlanningScene 杆与物理杆一致后，把单个 `aluminum_rod` 附着到左手。MoveIt 每个物体空间航点均按固定变换反推双手目标并规划/执行；轨迹再检查限位、自碰撞、关节跳变和双手间距。MoveIt touch links 仅为左右抓持 hand parent 与四个指链接；未更改全局 ACM，其他臂连杆、地面和环境仍检查。

为修复实际运行暴露的问题，附着位姿现在使用 `object.pose * primitive_poses[0]`，并在移除 world object 前与 MuJoCo 真值核对，超出 5 mm/5°拒绝附着。首次运行证明旧读取把杆附着到原点。S1 runner 配置中的 `/get_sim_info` 单次等待从 2 s 调为 5 s，以满足初始化阶段服务响应；源码未改该 timeout。
