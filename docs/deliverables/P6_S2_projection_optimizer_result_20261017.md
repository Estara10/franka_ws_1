## 1. 结论

**B：闭环实现正确，但在冻结目标与冻结样本上没有明显几何收益。**

- 优化器确实改变了几何路径，并满足全部约束；在**本样本、本目标、30 轮预算**内，
  目标由 `J0=1.100000` 降到 `J1=1.083785`，**约 1.5%**（同实现的前一版步长规则为
  2.17%），远低于 20% 门槛。
- 数值诊断：任务 Jacobian 满秩 `rank=12`（左右各 6），零空间 `null_dim=2`，
  投影梯度 RMS `6.259`，远高于驻点阈值 `1e-6`，所以**不是**驻点早停。
  30 轮接受 30 步说明的是**预算耗尽**，不是收敛，也不是达到局部最优。
- 最终规划时间与 jerk 没有改善：时长 `1.0957 → 1.0965 s`（+0.07%）、
  `jerk_rms 52.12 → 52.38`（+0.5%），仍在同一套 5 mm / 2°、限位、速度、
  加速度与碰撞检查内。
- 现有证据已足以决定**不再继续投入这条几何路线**，因此不需要（也没有）证明全局最优。
- **未达到下一轮基线/优化各 3 次执行对照的门槛**，本轮不安排搬运对照。

本轮仅验证离线几何与规划轨迹指标，未验证执行收益，不宣称滑移、接触力或实际成功率改善。

## 3. 算法

新增 `coordinated_path_optimizer.{hpp,cpp}`（纯 Eigen，无 ROS 依赖；FK、任务 Jacobian
和可行性检查通过回调注入），接入 `contact_load_probe.cpp` 的 `makePlan`。

变量为内部航点 `q_k ∈ R^14`；起终关节状态与物体路径 `X_k` 固定。
目标（几何平滑度，**不是**时间 jerk、能耗或接触力）：

```text
J = w2*A2/S2 + w1*A1/S1 + w0*A0/S0
A1 = Σ_k ||q_{k+1}-q_k||² / Δs_k
A2 = Σ_k h_k ||d2_k||²
   d2_k = ((q_{k+1}-q_k)/Δs_k − (q_k−q_{k−1})/Δs_{k−1}) / h_k
   h_k  = (Δs_{k−1}+Δs_k)/2
A0 = Σ_internal ||q_k - q_seed_k||²
S1 = max(A1_seed,1e-12),  S2 = max(A2_seed,1e-12),  S0 = 14·N_internal·(0.1 rad)²
```

`d2_k` 用**差商**表示二阶导数。直接取 `q_{k+1}-2q_k+q_{k-1}` 只在等距网格上才是二阶导数，
非等距网格上不是；本轮已按上式修正（见 6.6）。

关节以 rad、路径参数归一化到 [0,1]；非等距网格按各自间隔加权；无内部航点直接报不适用。

每轮：解析目标梯度 → 12×14 任务 Jacobian（中心差分，14 个变量 × 双侧位姿）→ SVD 求
数值秩、零空间投影与阻尼最小二乘 → 每航点 `Δq = J⁺(-e) + α·P·(-∇J)`。
目标各项都是 `q` 的二次型，因此沿固定方向 `J(α)` 是**精确二次函数**：每轮用一次目标
求值测出曲率，直接取该方向上的精确最小步长，再由 5 个几何回溯候选步长（`1, 0.1,
0.01, 1e-3, 1e-4`）处理碰撞/限位等可行性拒绝。最多 30 轮，无可接受改善即退出。

注意：由于 S1/S2 取种子值，`J(seed) ≡ w2 + w1 + 0 = 1.1` 对任何种子都成立；因此
“目标下降百分比”总是相对于 1.1 计算，正则项初值为零且不作为自己的分母。

|---|---|

### 6.3 诊断

初始投影梯度 RMS `6.259`，远高于固定阈值 `1e-6`；30 轮中每一轮都有可接受步，
30 步后目标仍下降 1.47%。因此可以排除两种解释：**不是**“接近驻点提前退出”，
也**不是**“所有候选都被可行性拒绝”。本轮没有进一步定位收益偏小的原因，
这不在本轮范围内；现有证据（同一目标、同一样本、30 轮预算约 1–2%）已经足够
决定不再继续这条几何路线。

### 6.4 实现修正（非权重调整）

运行日志暴露两处实现问题，均已修正并记录，**未改动**权重、尺度、驻点阈值、样本场景或约束：

1. 样本起点的关节状态：A1 保存的抓取解除按名读取时全为 0（同一状态的 FK 却与抓取目标
   一致），因此改为**直接用 A1 抓取目标位姿在本轮 live 模型上做双臂 IK** 重建起点，
   并在日志中给出抬升位姿与双手位置。
2. 步长：归一化目标极硬（`1/S2≈2.7e6`），固定 0.02 rad 步长比所需步长大若干数量级。
   目标各项都是二次型，因此改为**沿投影方向的精确二次线搜索**（一次目标求值测曲率），
   再以 5 个几何回溯步长处理可行性拒绝。

作为对照，采用较小固定步长与几何回溯的中间版本（run `..._r8`）得到
`J 1.100 → 1.076`（−2.17%）。两种步长规则给出的结果都在 1–2% 量级，
步长策略不是这一量级差异的主要来源。

### 6.6 二阶差分修正（本轮，独立记录，不改写上面的运行结果）

`objectiveTerms` 与解析梯度已由 `q_{k+1}-2q_k+q_{k-1}` 改为差商二阶导 `d2_k`（公式见第 3 节）。
权重、正则尺度、约束、迭代预算与样本均未改动。

**对 r11 结果的影响：保持不变。**

- 运输航点的路径参数是 `s_k = k/kPathSteps`，**等距**（`contact_load_probe.cpp` 的
  `params.push_back(double(k)/kPathSteps)`）。
- 等距网格上 `d2_k = (q_{k+1}-2q_k+q_{k-1})/h²`，因此 `A2_new = A2_plain/h⁴`；
  种子尺度 `S2` 同比例缩放，归一化项 `A2/S2` 与 `A1`、`A0` 的归一化项都不变，
  目标、梯度方向和优化轨迹在数学上不变。该不变性由
  `UniformGridNormalisedSecondTermIsStencilInvariant` 直接验证。
- 因此 r11 的 `J0/J1`、约束检查与最终轨迹指标继续作为本样本的有效结果保留，
  未被覆盖、未重算。

**未做与缺项（如实记录）：**

- r11 保存的数据只有 `transport_path_compare.csv` 的逐采样位姿/残差和
  `contact_probe.csv` 的杆与双手位姿，**没有保存 14 关节航点路径**，
  因此无法纯离线在真实路径上重算修正后的归一化目标。
- 按任务约定不为此重启仿真，也没有补跑 3+3。**修正后的实现本轮没有在真实双臂模型上
  运行过**；它的验证只到：数学测试 + “运输网格等距 ⇒ 归一化目标不变”这一论证。
  一旦改用非等距网格，必须重跑离线对照，不能沿用 r11 的数字。

## 7. 限制与后续

- **本轮仅验证离线几何与规划轨迹指标，未验证执行收益，不宣称滑移、接触力或实际成功率改善。**
- 样本是重建的离线规划样本，不是实测运输起点：实测运输起始关节状态与杆姿态没有被保存。

- 目标函数是几何平滑度；`A1/A2` 不是时间 jerk、能耗或接触力指标。表中的 jerk 来自

- 单样本、单次，不含统计意义；没有执行，也没有进入 S3。
- 修正后的二阶差分实现在本轮**没有**在真实双臂模型上运行（见 6.6）；能用的是数学测试和
  “运输网格等距 ⇒ 归一化目标不变”的论证，不是新的模型侧实测。
- 30 轮接受 30 步只说明预算用完，不说明收敛或局部最优；本轮没有做收敛性证明，也不打算做——
  1–2% 的结果已足以停止这条几何路线。
- 本轮把 `makePlan` 拆成“航点构建 + 可行性/插值校核 + 计时”三段，运输段基线仍走同一份
  代码且在本轮被完整执行；但**生产接触搬运流程本身本轮没有重跑**（任务书禁止执行搬运），

- 后续退路（本轮不实现）：在**同一条** `q(s)` 上做受约束时间剖面优化（分段 jerk 受限的
