# 结题目标修订说明：仅仿真验证

项目名称：基于 Franka 双臂协作的物体搬运轨迹优化与柔顺控制研究。

本说明根据当前工作空间、中期检查报告及用户明确的范围调整编写。已确定的调整是：
**本次结题不进行实际机器测试，所有实验和演示均在仿真中完成。** 下文的实验次数、
统计口径及未在项目指南中明确的验收建议属于修订方案，不表示已获学校或指导教师批准，
也不表示相关功能和指标已经完成。

中期检查报告保留为历史材料。本说明用于后续结题报告、开发安排和实验设计；当前架构、
能力边界和阶段顺序以 [项目指南](../PROJECT_GUIDE.md) 为准。

开发标准遵循项目指南的“项目定位与长期开发准则”：本项目以大学生创新训练的研究与
实践为目标，采用必要测试和基本实验记录。下文实验规模与指标设计用于研究评价，不作为
每次调试的强制审批条件，不要求全量哈希、工业级审计或先完成全部辅助规范再实现算法。

## 1. 项目理解与当前基础

项目研究的是两台 Franka Panda 协同夹持长条刚性物体时的轨迹协调、运动平滑性和受力
协调。任务对象尺寸为 40 cm × 4 cm × 4 cm，目标质量为 0.5 kg。当前 MuJoCo 模型约为
0.64 kg，正式实验前需要统一模型参数并重新验证；既有数据须保留其实际模型版本。

当前主链为 ROS 2 Humble + MoveIt 2 + ros2_control + MuJoCo，活动实现位于
`src/multipanda_ros2`。任务状态机执行接近、抓取、物理稳定等待、抬升、运输、旋转、下降、
放置和撤退。MuJoCo 通过双手与物体的 weld 约束实现协作抓持，MoveIt 使用附着碰撞物体
维护规划场景；两侧对象状态的一致性是后续验证重点。

| 内容 | 当前基础 | 结题前需要补充的证据 |
|---|---|---|
| 完整任务 | A0 固定场景已有成功运行记录 | 多次独立运行、物体实际放置状态与失败记录 |
| 轨迹规划 | Pilz PTP、逐点 IK、TOTG，部分路径使用 Ruckig | 协调 IK、完整碰撞有效性、真实优化和统一时间参数化 |
| 轨迹优化 | 注册了 CHOMP，历史模式名含 `chomp` | 核心任务实际调用优化器的链路及优化前后轨迹；调参不等于 CHOMP |
| 内部柔顺 | 基于内力的自适应关节伺服增益 | 固定轨迹下受力、振动和跟踪精度的重复对比 |
| 外部阻抗 | 参数监督器框架，默认关闭 | 连续末端目标、控制器切换、力矩限制、超时保护及仿真执行 |
| 随机场景 | A1 尚待开发 | 固定 seed、样本有效性检查、接受和拒绝记录 |
| 视觉 | 模式 B 为实验框架 | 不列入当前核心验收，完成后单独报告 |

当前监控中的同步误差是双末端相邻采样位移长度之差，末端误差是 DESCEND 阶段的双手
位置误差，能耗是代理量；它们不能直接证明闭链约束、杆最终放置精度或实际电能消耗。
例如既有 `20260821_194653` 运行报告终态为 DONE，但末端误差为 2.671 mm，仍未通过
2 mm 阈值。单次成功和自动 PASS 标签不能替代正式验收。

## 2. 可用于结题报告的目标修订文本

结题阶段以双臂协作搬运系统完善与仿真验证为核心，在 ROS 2、MoveIt 2、ros2_control
和 MuJoCo 平台上开展轨迹优化与柔顺控制研究，完成已知物体位姿条件下的双臂协同抓取、
抬升、搬运、旋转与放置任务，形成可复现、可展示、具有定量实验依据的仿真研究成果。
本项目结题不开展实际机器测试，研究结论限定于所建仿真模型和实验条件。具体目标如下：

（1）**系统功能完善与集成优化。** 完善双臂任务状态机、规划场景与仿真对象的一致性、
异常处理和实验数据记录。以物体空间轨迹及固定抓取变换为基础，研究协调逆运动学、
碰撞约束下的轨迹优化和双臂统一时间参数化，形成可执行的规划与控制链路。

（2）**轨迹优化与柔顺控制的仿真验证。** 在 MuJoCo 中完成完整协作搬运流程，以未优化
轨迹和固定增益位置控制为基线，分别评估轨迹优化、基于力反馈的柔顺调节及二者结合的
作用。保留现有内部柔顺作为基线，推进完整外部笛卡尔阻抗链路的仿真验证，并根据成功率、
跟踪精度和受力稳定性决定正式采用的控制方案。未完成或不稳定的方案单独列为实验性结果。

（3）**可复现实验与定量性能评估。** 在固定场景、已知真值的随机初始位姿场景及受控
扰动条件下开展重复仿真实验。记录任务成功率、执行时间、轨迹平滑度、双臂相对位姿误差、
末端跟踪误差、物体最终放置误差、受力协调和能耗代理量，分析算法收益及适用边界。

（4）**成果总结与展示。** 整理源码、环境说明、模型参数、实验配置、原始数据与分析
方法，完成结题报告和仿真演示视频。展示已验证的轨迹优化与柔顺控制结果，明确尚未达成的
指标及仿真建模限制，为后续多臂协作研究提供可复现参考。

## 4. 仿真实验设计建议

根据用户最新安排，从 A1 的接口与可复现场景开始推进，随后完成有效性检查、必要的
可靠性修复、全流程泛化、真实优化及柔顺对比，最后开展正式实验。A0 全程作为回归基线。
详细依赖与验收门槛见 [阶段计划](从A1开始的阶段计划与执行器提示词.md)。

下列次数是正式研究的建议规模，可按时间、资源和结果波动调整并说明。功能调试可以先做
少量实验；不因未达到建议次数、非关键日志或格式问题停止后续开发。

- **固定场景 A0：** 建议每个正式实验组至少进行 10 次独立重置运行，检查整个状态机、
  物体放置和释放后的稳定状态；不得只检查 DONE。
- **随机场景 A1：** 建议采用同一组至少 30 个有效 seed 比较各算法。先依据桌面边界、
  双臂 IK、组合碰撞和预抓取路径检查接受样本，保留所有拒绝原因。接受后出现的规划或
  执行失败必须计入任务失败，不能事后删除；采样接受率与任务成功率分别统计。
- **柔顺与扰动：** 使用同一参考轨迹，分别比较固定增益、内部柔顺和完成后的外部阻抗。
  固定外力方向、大小、持续时间和施加阶段，记录超调、恢复时间、跟踪误差与受力变化。
- **参数敏感性：** 在标称模型验证后逐项改变质量、摩擦或扰动强度，记录实际参数。
  焊接抓取约束会限制滑脱与接触行为，因此结论须说明其适用范围。

正式对比组计划为：无优化无柔顺、仅优化、仅柔顺、优化与柔顺结合。只有实际优化链路
完成后才设置“优化”组；研究控制方案时，把内部柔顺与外部笛卡尔阻抗作为独立子组。
同一比较必须控制模型、初始状态、目标、速度限制及评价阶段；轨迹优化和控制增益的作用
应分别比较。当前四种历史命令行模式不能直接视作上述四组已实现的消融实验。

## 5. 指标与报告口径

以下数值沿用中期报告的研究目标及项目指南的精度方向，不是已完成指标。正式验收还需
冻结评价区间、统计方式、参考轨迹和数据质量规则。建议将功能完成与性能达标分别报告。

| 指标 | 目标或建议 | 测量与解释 |
|---|---|---|
| 完整任务与成功率 | 必须完成全流程；重复次数见上节，成功率如实报告 | 成功需包括目标放置、解除抓持和稳定停留；同时记录 ERROR、超时和物体异常 |
| 双臂空间协调误差 | 原目标 ≤5 mm | 在同一坐标系和时间下，由实际双手变换与固定抓取关系计算相对位置残差；同时报告姿态残差 |
| 末端跟踪精度 | 2 mm 优化目标，3 mm 阶段性功能门槛 | 根据期望和实际末端位置计算，注明 RMS、P95、最大值及终值；3 mm 不替代 2 mm 达标 |
| 物体放置误差 | 单独报告，不自动沿用末端阈值 | 解除 weld、打开夹爪并稳定后，比较杆真值与目标位置及姿态，预先固定停留窗口 |
| 执行时间缩短 | 原目标 ≥15% | 同场景同阶段比较仿真时间；另报规划计算的墙钟时间和整周期时间 |
| 能耗代理量下降 | 原目标 ≥10% | 统一采用如 ∫Σ\|τᵢq̇ᵢ\|dt 的机械做功代理，注明力矩来源；不解释为真实电能 |
| 受力协调 | 原目标受力差/波动 ≤15%，需明确两者定义 | 同坐标系、扣除偏置并明确载荷补偿后，建议用 \|F_L−F_R\| / max((\|F_L\|+\|F_R\|)/2, F_min)；报告阶段统计，预先固定 F_min 和滤波 |
| 内力与振动 | 比较峰值、RMS 与改进幅度 | 双腕力差不是完整内力；需明确物体坐标系、抓取变换和内力分解，未实现则标为代理量 |
| 扰动恢复时间 | 原目标 ≤1 s | 从扰动结束到误差进入并持续保持于预设容差带，预先固定容差及保持时长 |
| 平滑度 | 报告加速度与 jerk 的峰值、RMS 或积分 | 在同一采样率下比较，不以轨迹外观替代数值验证 |
| 采样与控制频率 | 原 50 Hz 目标需区分测量对象 | 记录控制循环、监督器和监控实际频率及抖动；20 ms 定时器配置不能证明力控达到 50 Hz |
| 消息时效 | 原阈值 100 ms，明确统计量 | 同一时钟域报告 P95、最大值及无效/负延迟样本；仿真消息年龄不代表实机网络实时性 |

原报告的底层 1 kHz 描述不作为已验证的硬实时性能。仿真步长、ros2_control 更新频率和
运行实时因子应分开记录。性能目标未达到时，应给出实际值和原因，避免只筛选成功样本。

## 6. 结题交付物与结论边界

交付内容建议包括：可运行的仿真工程与启动说明、固定与随机场景配置及 seed 清单、
模型参数与代码版本、原始数据和失败记录、指标定义及分析脚本、对比图表、结题报告和
完整任务演示视频。结果应标明仿真时间或墙钟时间、控制方式、优化器及抓取约束模型。

结题报告只能依据实验说明算法在指定仿真条件下的表现。不得声称已通过实机验证、已证明
真机安全或具备工业部署能力；也不得将单纯的 weld 抓取成功推广为真实夹持抗滑脱性能。
真实硬件迁移、视觉闭环和更复杂物体任务可作为未来研究方向。

本次文档修订未改变运动、碰撞、控制器或硬件接口实现，也未运行新的仿真实验。
