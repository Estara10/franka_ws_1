# 释放后手臂退回（retreat）记录（2026-10-17）

状态：已实现并跑通一次。有效 run：
`experiment_results/a1_runs/lidio_contact_probe_yaw10_20261017_200029`（DONE，退出码 0）。

## 1. 实现

在释放检查与场景同步之后增加一段自由空间退回：

1. 用释放瞬间的实测状态重新冻结 `object_to_hand`（只用于两臂协调，杆已不受约束）；
2. `makePlan(..., delta=(0,0,0.15), "retreat", vscale=1.0, ascale=0.4, min_total=1.0)`；
3. 用新增的 `executeFree()` 执行：保留起始状态检查与 action 结果检查，
   **不执行**接触期的力模式/滑移/高度监控（释放后 force hold 已为 0）；
4. 记录 `[CONTACT_PROBE_RETREAT]`，最终 `detail` 增加 “release and retreat complete”。

不改接触参数、夹持力、滑移窗口、模型、ACM、验收判据。
