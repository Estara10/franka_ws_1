# 2026-10-25 B组三次正式实验

## 运行前确定的配置与统计

本批次独立于旧B组和10月24日修复验证。按用户要求重新执行B组3次完整搬运，不另设“B补充”组，不改变旧失败记录。

- 三次名称：`b_formal_20261025_01`、`b_formal_20261025_02`、`b_formal_20261025_03`。
- 固定场景：(0.50 m, 0, +10°) → (0.40 m, 0, +20°)。抬升参考0.40 m，抬升时间倍率1.5；运输伸时参数2.0、额外时间倍率1.0。
- 当前修正后的时间优化器，JTC执行，10 N/指请求，无weld、无载荷前馈、无外力扰动、内部柔顺关闭。
- 每次均打开窗口，依次运行，每次结束由既有脚本回收所属任务和仿真。
- 三次动作尝试均计入完成次数；以完成释放及撤退并返回DONE认定完整完成。动作前基础设施失败另记，不作为抓取/搬运结果，不丢弃发生动作后的失败，不以补跑凑满成功次数。
- 保存连续参考jerk RMS及峰值、运输计划及实际耗时、优化求解耗时、释放位置/姿态误差及任务结果。参考jerk不表述为实测机械臂jerk。
- 完成后更新新B组汇总和四组展示图。保留A/C/D原批次，明确B为本次更新批次及方法版本，避免写成同一批同步对照。
