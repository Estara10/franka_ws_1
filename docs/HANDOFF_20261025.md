新批次与ABCD及10月20日专项分开。冻结表60个计划样本均进入正式计数：F0/F1各10次；K400-N、K400-F、K200-N、K200-F各10次。恢复过程中因一次临时状态误判额外运行了K200-F_06_a2，保留原始数据但不纳入60样本统计。另有7次动作前启动/规划异常；K200-N_04正式中止且无有效窗口，K200-N_05有完整5 s测量但随后下降阶段接触滑移/掉落、未完成。二者均保留，不补跑。

- **载荷前馈：** 同一400 N/m阻抗下，3.5 s杆ΔZ均值F0 −9.084±0.665 mm、F1 −2.997±0.538 mm；有符号F0−F1差−6.086 mm（95% Welch区间−6.656至−5.516，n=10/10），相当于本场景观测下沉幅度约减少6.1 mm。F0双臂trace全窗为0 N；F1均达每臂3.1392 N，采样trace的渐增时间约0.519 s。
- **方向性刚度：** 2 N、1 s +X脉冲扣除无力组背景后，杆脉冲末平均响应K400=1.490 mm，K200=2.004 mm；K200多0.515 mm（95% Welch区间0.387至0.643，四组独立差中差）。左/右手对应额外响应约0.392/0.401 mm，杆手相对位移也有变化，不能将其称为指垫滑移。撤力后1 s的杆响应估计为0.557/0.996 mm，撤力后共同实测2.891 s为0.245/0.442 mm；恢复不完全，低刚度残余较大。杆竖向下沉约2.4–3.0 mm、姿态变化约0.24–0.25°；K200-N任务完成8/10，其余条件10/10。
- 结论仅限固定场景、无weld悬空保持的仿真对照：重复支持载荷前馈减小下沉，也支持降低X刚度后杆与双手的净X响应有所增加；不证明完整运输或真机效果。此次样本足以回答两个限定问题，不建议为追求更好的数值追加同条件重复。若要扩大到不同姿态、载荷或实际搬运，需另立研究问题。
