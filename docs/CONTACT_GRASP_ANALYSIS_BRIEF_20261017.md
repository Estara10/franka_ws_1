## 1. 任务与判据

两台 Franka Panda 各带一个双指平行夹爪，从两端夹住同一根铝杆，完成：

```text
闭合 → 抬升 5 cm → 保持 2 s → 落回支撑面 → 松开
```

验收（未放宽）：

- 杆相对初始上升 ≥ **45 mm**；
- 保持 ≥ **2 s**；
- 杆相对任一手的抓取参考漂移 ≤ **5 mm / 2°**；
- 每指受力样本占比 ≥ 80%；
- 全程 weld / equality / 杆固定约束必须为 0；
- 只允许四指与杆接触，其余碰撞照常检查。

当前状态：**真实接触抬升从未通过**。最好的一次杆只升 0.53 mm，滑移 5 mm 触发失败。

## 2. 模型与参数

### 2.1 场景与求解器

模型：`dual_scene.xml`（include `mj_dual.xml` + `objects.xml`）。

```xml
<option timestep="0.002" integrator="implicitfast" iterations="50"
        tolerance="1e-9" solver="Newton" jacobian="dense" cone="pyramidal"/>
```

- 未设置 `impratio`、`noslip_iterations`、`noslip_tolerance`，因此实际为默认值
  `impratio=1`、`noslip_iterations=0`（关闭）。
- 运行中曾单独做过 `impratio=10` 与 `noslip_iterations=2` 的对照（见第 4 节）。

### 2.2 铝杆

```xml
<body name="obj_rod_01" pos="0.50 0.00 0.02" euler="0 0 0">
  <geom name="obj_rod_01" type="box" size="0.02 0.2 0.02"
        density="1000" friction="3.0 0.5 0.005" condim="6"
        solref="0.005 1" solimp="0.99 0.999 0.001"
        margin="0.001"/>
  <freejoint/>
</body>
```

- 尺寸 0.04 × 0.40 × 0.04 m，质量约 **0.64 kg**，重力 **6.28 N**。
- 支撑面为 z=0 的 plane；杆初始中心 z≈0.020654 m（底部与平面间约有 0.65 mm 的
  margin 接触间隙，处于 1 mm contact margin 内）。

### 2.3 手指与 pad

每根手指同时保留一个碰撞 mesh 和 5 个 pad box（1 个主 pad + 4 个辅助小 pad）：

```xml
<geom type="box" size="0.0085 0.004 0.0085" pos="0 0.0055 0.0445"   <!-- 主 pad -->
      friction="3.0 0.5 0.005" condim="6"
      solref="0.01 1" solimp="0.95 0.99 0.001" margin="0.001"/>
<geom type="box" size="0.003 0.002 0.003"  pos="0.0055 0.002 0.05"  .../>  <!-- 辅助 pad ×4 -->
```

运行时 `CONTACT_PROBE_SINGLE_PAD` 会：

- 把 16 个辅助 pad 的 `contype/conaffinity` 置 0；
- 把 4 个主 pad 的 `size` 改为 `(0.010, 0.006, 0.010)`，`solref` 改为 `(0.02, 1)`；
- 安装一个用户接触过滤器，丢弃 finger collision mesh 与杆的接触对。

手指关节：

```xml
<joint axis="0 1 0" type="slide" range="0 0.04"
       armature="0.1" damping="1" frictionloss="0"/>
```

同一夹爪两指之间有 joint equality 同步约束（`solref="0.005 1"`，
`solimp="0.95 0.99 0.001"`）；它不是手–杆固定约束。

### 2.4 夹爪驱动

```xml
<tendon>
  <fixed name="mj_left_split">
    <joint joint="mj_left_finger_joint1" coef="0.5"/>
    <joint joint="mj_left_finger_joint2" coef="0.5"/>
  </fixed>
</tendon>
<position name="mj_left_act_gripper" tendon="mj_left_split"
          kp="1200" forcerange="-150 150"
          ctrlrange="0 0.08" ctrllimited="true"/>
```

接触保持时的实际做法（`contact_probe` 分支）：

- 触杆后锁存腱长 `L_ref≈0.021 m`；
- 固定位置目标 `ctrl = L_ref − 0.015 m`（即请求 10 N/指时的名义预压）；
- 物理线程把该 actuator 的 `forcerange` 临时设为 **±20 N**，退出时恢复；
- 实测 actuator force 约 **−17.6 … −18.1 N**，每指约 9–10 N；
- 普通位置命令与 `ideal_weld` 不走该分支。

注意：位置伺服在 `ctrl=0` 时最大只能给出约 `kp·L/2 ≈ 12.5 N/指`；
请求超过约 14 N/指时，固定位置目标会越出 `ctrlrange (0,0.08)` 并触发 fault。

### 2.5 手臂控制与轨迹

- 双臂关节位置控制（`dual_panda_arm_controller`），`contact_probe` 使用 rigid 配置，
  内部自适应柔顺关闭。
- 抬升轨迹在物体空间生成：5 cm、2.5 mm 步长、每段至少 1 s，IPTP 后统一时间伸缩，
  计划时长 **31.91 s**。
- 执行时监控杆相对双手抓取参考的滑移，超过 5 mm / 2° 立即停止。

## 3. 已确认的实测事实

以下数据来自 MuJoCo 物理线程逐接触 CSV 与任务 CSV，不是估算。

### 3.1 接触几何（最近一次有效几何运行 `130603`）

- 杆–指接触只来自 **4 个主 pad**（geom 69/77/150/158），无辅助 pad、无 mesh。
- 接触位于杆的**左右侧面**：杆局部坐标 `x≈±19.3…19.5 mm`（杆半宽 20 mm）。
- 接触法向几乎水平（`normal_z` 中位 0.0000，p5/p95 = −0.0023/+0.0023）。
- 穿透深度 `contact_dist ≈ −0.51…−0.66 mm`。
- 每夹爪 **8 个接触点**（4 pad × 2 点），不是面接触的 4 点。
- 接触混合 `solref = 0.0125`（pad 0.02 与杆 0.005 平均），`condim=6`，
  摩擦 `(3.0, 0.5, 0.005)`。

### 3.2 力与摩擦利用率

- 每接触点法向力中位 **2.48 N**；每指约 10 N；摩擦锥容量约 **7.4 N/点**，
  合计约 60 N。
- 切向力中位约 **0.115 N/点**。
- 摩擦锥利用率 `|t|/(μN)`：中位 **1.65%**，p90 **3.71%**。
  **接触离滑动摩擦上限极远。**

### 3.3 净向上力 vs 滑移（最关键的定量关系）

对上一次几何正确、进入 LIFT 的运行 `130603`：

```text
F_up ≈ 1.31 N + 0.54 N/mm × 滑移
5 mm 时 F_up ≈ 3.92 N
达到杆重 6.28 N 需要约 9.5 mm 滑移
```

时间序列上是近似线性的缓慢累积，没有出现摩擦锥饱和。

对照：修复前使用辅助 pad 的运行 `113058`，`dFz/dslip` 约 270 N/m，
5 mm 时约 3.1 N，杆升 0.53 mm。

### 3.4 接触寿命与速度依赖

- 主 pad 接触点连续存在时长：中位 **0.27 s**，p90 0.32 s（trace 采样 0.02 s）。
- 切向力随相对滑移速度上升：
  - `<0.5 mm/s`：利用率中位 0.7%
  - `0.5–1.5 mm/s`：2.4%
  - `1.5–4 mm/s`：13.3%
- 但切向力**不随接触年龄累积**：0–0.05 s、0.05–0.15 s、0.15–0.3 s、0.3–0.6 s
  四档的利用率中位都在 1.5–1.9%。

### 3.5 两只手的运动

`130603` 中，LIFT 期间：

- 左手升 5.78 mm，右手升 5.42 mm；
- 杆升 0.19 mm；
- 相对手–杆位移的竖直分量约 5.7/5.3 mm，水平（沿杆轴）约 0.2/0.5 mm；
- 杆姿态变化约 0.04°。

即：**滑移基本是竖直方向的**，不是轴向或转动。

## 5. 已排除或明显削弱的假设

- **夹持力不够**：法向约 10 N/指，μ=3，锥容量约 60 N；实际切向力只有约 2–4 N，
  利用率 <4%。加力不会改变约束刚度。
- **摩擦系数太小**：系数只决定锥上限；上限远未用到。把 μ 从 3 提到 6 不会改变
  切向力-滑移曲线。
- **接触几何/擦边**：接触在杆侧面、法向水平、四个主 pad、穿透 0.5–0.7 mm。
- **mesh/辅助 pad 干扰**：修复后只剩四个主 pad。
- **ROS 运动链/两指不同步**：固定手臂最小复现也失败；两指 q1−q2 差只有约 0.06 mm。
- **两指 equality 失配**：现有数据不支持它先失稳。

## 6. 两个已经确认的实现层事实（可能影响你的分析）

### 6.1 用户接触过滤器会替换 MuJoCo 内置掩码过滤

MuJoCo 3.2.0 `src/engine/engine_collision_driver.c`：

```c
if (ipair < 0) {
  if (mjcb_contactfilter) {
    if (mjcb_contactfilter(m, d, g1, g2)) return;
  }
  else if (filterBitmask(m->geom_contype[g1], m->geom_conaffinity[g1],
                         m->geom_contype[g2], m->geom_conaffinity[g2])) {
    return;
  }
}
```

是 `else if`。安装用户过滤器后，内置的 contype/conaffinity 过滤**整段不执行**。
本项目曾因此在“禁用 16 个辅助 pad”之后仍看到它们参与碰撞；现在过滤器回调里
已显式复现 `filterBitmask`，接触才回到 4 个主 pad。

### 6.2 `solreffriction` 只对 elliptic 锥生效

MuJoCo 3.2.0 `src/engine/engine_core_constraint.c`：

```c
int elliptic_friction = (tp == mjCNSTR_CONTACT_ELLIPTIC) && (j > 0);
mjtNum* ref = elliptic_friction && (solreffriction[0] || solreffriction[1])
              ? solreffriction : solref;
```

本模型是 `cone="pyramidal"`，所以显式 `<pair solreffriction=...>` 对摩擦
**不会生效**。要走这条路必须先改锥模型。

## 7. 当前的核心矛盾（请重点分析）

把数据放在一起，得到一个很窄的两难：

- **软接触（0.02）**：闭合窗稳定，但切向刚度只有约 540 N/m，5 mm 滑移只产生
  3.9 N，达不到 6.28 N；按趋势需要约 9.5 mm。
- **硬接触（0.01）**：闭合阶段就失稳（occupancy 12/20、单指失接触）。
- **更硬（0.005）**：闭合阶段用 0.02 可以过，但切换后接触点成片丢失
  （60% 采样每臂 ≤1 个 pad），切向力不升反降。

也就是说：**稳定性和刚度在 2 ms 时间步长下似乎互相排斥**。
0.005 s 的接触时间常数只有 2.5 个时间步长（MuJoCo 的 `REFSAFE` 下限是
`2·timestep = 0.004 s`），已经接近数值稳定边界。指关节还有 0.1 kg 的 armature，
接触刚度一高，手指-接触系统的固有频率可能超出 500 Hz 仿真的稳定范围。

### 12.2 关键新证据：接触点在杆侧面持续上移

用杆真值位姿把接触点转到杆局部坐标（杆高 ±20 mm），统计每个采样时刻所有杆–pad 接触点的 z 范围：

| run | 起始 z 范围 (mm) | 抬升末 z 范围 (mm) | 备注 |
|---|---|---|---|
| E5 | −10.8 … +9.2 | −6.4 … +14.4 | 杆升 31.4 mm |
| E6 | −10.8 … +9.2 | −4.6 … +16.0 | 杆升 39.9 mm |
| E7 | −10.8 … +9.2 | **−0.8 … +20.0** | 保持失败时接触点已到**杆顶边** |

主 pad 的 z 半尺寸是 **0.010 m（高 20 mm）**，杆高 40 mm。随着杆相对 pad 向下滑，接触点在杆侧面从中心一路向上移动；E7 在保持失败时已经到 +20 mm，正好是杆的顶边，随后右指失接触、杆滑落。

### 12.3 对“有速度能夹、静止夹不住”的初步解释

目前最一致的解释不是“速度本身产生抓力”，而是：

> **快速抬升在滑移预算耗尽前就完成了；静止保持继续消耗剩余的滑移预算，接触点到达杆顶边后脱落。**

速度相关摩擦仍可能是次要因素（保持时净向上力均值 4.64 N < 6.28 N），但**几何滑移预算**（pad 在杆侧面的接触行程 + 杆高）是当前最直接、可量化的限制。

## 13. 2026-10-17 晚更新：问题已定位并跑通

后续有界实验确认：

- **提高抬升/落回速度会提高切向摩擦并降低滑移**：50 cm 抬升在最大速度下约 12.9 mm 滑移，落回段从 0.6 提到 0.8 加速度后由约 21 mm 降到约 4 mm；
- **`noslip_iterations=20` 进一步抑制蠕滑**：保持期杆下滑从约 8 mm/3 s 降到约 2.4–4 mm；迭代过高会降低接触连续性；
- **降低抓取高度（偏移 0.0073→0.0123 m）增加滑移预算**，并配合落回前重建立抓持参考、按杆实际倾斜角落回、释放位姿与松爪前实测比较。

固定场景已完整通过“抬升 50 cm → 保持 3 s → 前进 10 cm → 落回 → 释放”，无 weld，`state=DONE`；杆相对手仍有约 10.8–11.4 mm 滑移。详见 [CONTACT_HANDOFF_20261016.md](CONTACT_HANDOFF_20261016.md) 的 E8–E10。
