## Output index

- `schedule.csv`: frozen 80-sample randomized order.
- `attempts.csv`: run IDs, wrapper exit codes, and raw run directories.
- `*_wrapper.log`: per-run runner output.
- `runs.csv`, `group_summary.csv`, `summary.json`, plots, and results markdown: generated by the analysis step after the scheduled runs are classified.

Formal-task classification is based on task logs and measured completion state, not the wrapper exit code alone. Startup failures before the first pre-grasp target dispatch remain separate and do not count toward the 20 formal attempts; if one occurs, preserve its directory and retry that sample with a new run ID.

## Runtime notes

- The headless launcher had a truth-readiness wait that did not notice the scene runner had exited after writing a failure manifest. `scripts/a1_run_scene.sh` now stops that wait as soon as its runner exits without publishing truth. This is a startup failure propagation fix; it does not change motion, control, or outcome criteria.
- Three C-group startup runs reached the external-impedance preflight but timed out waiting for `/controller_manager/list_controllers` within the existing shared 4 s deadline. The run-local `controllers.txt` snapshots for C08/C13/C16 show JTC active and MMC inactive, while MuJoCo reports it could not return the timed-out response after the client abandoned it. The permitted remedy is to preserve and retry once under the same settings; no deadline, gains, switching policy, or task behavior was changed.
- P2B PTP planning refusals occurred before any pre-grasp goal dispatch. Geometry/IK/static collision passed, but MoveIt returned `-2` with no trajectory. Diagnostic logs show self-collision contacts during Pilz planning. No collision rule or planner parameter was changed; the affected identifiers are recorded as pre-motion exceptions and are retried only in a new directory.
