# 已定位的动作前启动异常

M0预试验启动a1–a3使用ROS_DOMAIN_ID 261–263，超过Fast DDS支持上限232；仿真栈日志明确报“Calculated port number is too high”，未接受任何预抓取运动请求。

已将预试验域号改为224起的有效范围；正式域号沿用旧批次有效的180+2×sequence+launch_attempt分配。a4虽发现服务可发现，但场景准备阶段对`/get_sim_info`的现有5秒调用超时；MuJoCo随后记录“failed to send response ... (timeout)”，证明响应晚于客户端期限。旧r2也有两次相同的动作前现象。它没有接受预抓取运动，不是M0物理承载结果。

为区分接近DDS端口上界的域号影响，再允许一次限定恢复：a5使用此前已实际运行过动作的有效域号221，不改超时或实验参数。若再出现启动异常则停止，不继续重启。a1–a3均未接受预抓取运动；a4亦未接受预抓取运动。
