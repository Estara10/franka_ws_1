## 共同名义运输参考（本批次新增，动作前冻结）

1. **物体参考起点**：载荷前馈产生影响之前、夹持闭合后读到的杆真值位姿（`initial_truth`，杆模型原点
   为几何中心/质心）沿世界 `+Z` 平移 0.40 m。它与抬升计划的目标末端一致（抬升计划以同一
   夹持变换和同一 `+0.40 m` 位移生成），因此运输参考承接抬升阶段的计划末端目标。
2. **物体参考终点**：固定任务目标 `(0.400, 0.000, +20°)`，高度与起点相同。
3. **路径**：XY 直线 + 绕世界 Z 轴线性偏航，路径参数 `u∈[0,1]`。**物体路径本身**由第 1 条的
   前馈前名义位姿固定，不随两条件的下沉改变。
4. **抓持变换（用于生成双手参考）**：取运输起点的一次新鲜实测——当前关节状态与新鲜杆真值，
   左侧 `G_L = P⁻¹ H_L`、右侧 `G_R = P⁻¹ H_R`（P 为实测杆位姿，H 为实测手位姿）。原因是
   抬升/保持期间垫–杆已发生约 10 mm 量级滑移，接触时冻结的前馈前抓持与当前垫–杆相对位置
   相差约 20 mm；若仍用它生成双手目标，控制器会要求两侧指垫各做一次相当于重新夹持的相对
   运动，改变物理抓持。两种抓持变换均写入 `abcd_reference_meta.csv`，并记录前馈前抓持的
   双臂不一致量。这样**被下发的物体参考仍是固定的共同路径**，只是表达该路径的双手位姿
   取自本运行实测抓持；两条件的手参考可以不同，物体参考必须相同（由第 8 节检查）。
5. **时间**：主段固定总时长 **D = 3.040 s**，进度函数为五次平滑阶跃
   `u(t)=σ(τ)=6τ⁵−15τ⁴+10τ³, τ=t/D`；`u(t)` 与采样时刻网格（40 ms）在两条件间相同，
   因此共同物体运动使用相同进度函数，而不只是相同总时长。
6. **速度/加速度**：由 `q(t)` 对同一时间网格的中心差分给出，端点速度为 0、加速度为 0；经关节
   限位、闭链残差、碰撞与 `evaluateTransport` 的五次插值检查后才下发。

D 的选定依据（动作前）：原批次两次预试验计划时长 M0 3.0368 s、M1 2.2443 s；取其中较慢者并
圆整为 3.040 s。该时长已在相同场景执行过完整搬运（原 M0），本次在无运动规划检查中的
最大速度比 0.121、最大加速度比 0.055，两个条件均有充分余量。选择较慢者是为了两条件可执行，
不是通过大幅减速追求前馈正结果；M1 被统一到与 M0 相同的节奏，没有任何条件被加速。

## 起点衔接（与主段分开记录）

测量状态是唯一允许的起点。主段计划与衔接使用**同一次**运输起点实测（同一关节状态、同一新鲜
杆真值、同一抓持冻结），因此主段首点与衔接末点在整条轨迹上是连续的。衔接是一个
**0.5 s 笛卡尔回引**：按五次平滑进度把双手位姿从实测位姿带到“共同参考起点 × 该抓持”对应的
手位姿（位置线性、姿态 slerp），两臂对各自目标求解 IK。首点为实测状态，末点为主段首点，
两端速度/加速度为 0。衔接段：

- 使用与主段相同的关节限位、闭链、支撑与碰撞检查（承载过渡按既有 20 mm / 5° 残余判据）；
- 若实测物体偏移超过 50 mm 或 5°，本次动作按失败记录，不放大容差；
- 单独记录（`[CONTACT_TRANSPORT_COMMON_CONNECTION]`、`[TRANSPORT_MAIN_EVENT]`、
  `abcd_transport_start_connection.csv`、dispatch 轨迹首段），偏移量与双臂推断残差一并记录；
- 不计入主段指标；主段窗口从衔接结束开始。

衔接段是控制器把测量状态带回共同参考起点的真实动作，记录为控制响应；测量下沉不会被重新锚定
消除，而是保留为 `e_z(t)` 与衔接偏移的一部分。运输滑移监控与衔接校验使用同一份运输起点抓持，
从运输起点计量垫–杆相对运动；阈值不变。

## 参考差异的允许范围（动作前冻结，不因结果放宽）

| 项目 | 允许值 | 依据 |
|---|---|---|
| 主段计划/实际时长 | 与 3.040 s 之差 ≤ 0.020 s | MMC 参考发布周期 10 ms 的 2 倍 |
| 两条件共同参考起点 | 位置差 ≤ 1.0 mm，偏航差 ≤ 0.05° | 前馈前杆真值同场景重复测量与 IK 残差量级 |
| 匹配进度下的下发物体参考 | Δz ≤ 0.5 mm，Δxy ≤ 0.5 mm，Δ偏航 ≤ 0.10° | 现有 IK 残差判据 0.5 mm / 0.1° |
| 进度函数 | 相同 σ(τ) 与 40 ms 网格，逐点 `u` 差 ≤ 0.5% | 构造上相同，检查表达误差 |

仅当上述检查全部通过时，才把两条件的差异归因于前馈；否则只报告实际差异，不作效应解释。

## 测量口径

- 杆真值：MuJoCo body-state 异步请求/响应，采样时刻取请求与响应仿真时刻中点，并保留两者与区间宽度；
  只在数据与参考共同覆盖区间内插值，不外推，不把到达时刻当作精确物理采样时刻。
- 主段窗口：`[TRANSPORT_MAIN_EVENT start, end]`，均由仿真时间记录。
- 主要指标：`e_z(t₀)`（主段起点竖向误差）、`e_z(t)` 均值与 RMS、`Δe_z(t)=e_z(t)−e_z(t₀)` 末值与 RMS。
  `e_z(t)=实际杆中心高度−共同名义参考高度`。同时保存实际下发双手参考与由名义抓持变换推得的
  物体参考；若与名义参考有差异，单独量化。
- 补充记录：实际前馈（方向/坐标系/主段起点值）、杆姿态、释放位置与释放时姿态/偏航误差、
  完整任务完成情况、中止阶段、各指标有效样本数。
- 释放姿态取释放后统一物理等待结束时的真值（与释放 XYZ 同一时刻），不用释放前姿态代替。
  释放前比较基准取**开爪前**的一次新鲜真值请求（与既有“开爪前位姿”判据一致；
  阈值 10 mm / 5° 不变），避免把支撑面上的继续回稳误判为开爪跳变；释放比较量单独记录。

## 区组、顺序、计数

- 10 个位置/偏航小区组沿用原批次 `blocks.csv`（±2 mm、±0.4°），同一区组 M0/M1 使用相同外生
  初始条件；`schedule.csv` 中 5 个区组 M0 先行、5 个 M1 先行。
- 动作前核对区组输入确实生效：每次运行冻结真值位姿（任务日志）与 `abcd_reference_meta.csv` 的
  初始杆中心必须与该区组 `start_x/start_y/start_yaw` 一致（位置 ≤ 0.5 mm、偏航 ≤ 0.05°），
  且同区组 M0/M1 的初始真值差 ≤ 0.5 mm / 0.05°。
- 正式尝试自首次预抓取运动请求被接受起计；正式失败保留，不补跑替换。动作前基础设施异常
  单列，可在原因清楚后有界恢复；连续 3 次同类启动异常暂停；同一条件连续两次未进入运输暂停。
- 有效运输指标与完整任务完成情况分别统计；缺失值不补零。

## 预试验进入正式实验的条件

1. 两条件均完成抓取至撤退；
2. 实际主段采用共同物体参考、共同进度函数与 D=3.040 s；
3. 前馈开关及时序正确（M0 全程 0 N；M1 主段起点已达 3.1392 N/臂）；
4. 参考与实际杆状态具备可解释的时间对应（有效覆盖内可插值、样本数充足）；
5. 三项主要指标均可计算。

满足即进入正式实验，不看效应方向；不满足则报告原因并停止追加动作。
